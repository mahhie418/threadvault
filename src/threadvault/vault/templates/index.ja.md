# {product}

この vault は、{product} で作った Slack ワークスペースのバックアップです。形式のバージョン: {version}

- `{raw}/` には、ワークスペースの内容が Slack のエクスポートと同じ JSON 形式で入っています。`{users}`、`{channels}`、`{groups}` はユーザーとチャンネルの情報で、チャンネルごとのディレクトリには、メッセージが UTC の 1 日ごとのファイルに入っています。
- `{transcripts}/` には、メッセージがチャンネルごと、1 か月ごとの Markdown で入っています。時刻は {timezone} で、スレッドの返信は親の下にあります。
- `{attachments}/` には、添付ファイルが、アップロードされた月 (UTC) の下の、ファイル ID ごとのディレクトリに入っています。Markdown からはこれらのファイルにリンクしています。
